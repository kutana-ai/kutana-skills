# Write Good Instructions

The person approves an Assignment at a glance, and the agent runs it with nobody to
ask. Write for both.

- **Lead with the outcome.** "Draft the agenda for Thursday's planning meeting from
  the last three occurrences."
- **Name the sources.** Which meetings, repositories, documents or Integrations to read.
- **Name the output.** A Brief, a branch, a screen built ahead of time.
- **Say what not to touch.** "Read the repository. Do not push."
- **Give a finish line.** "Stop when the agenda has at most six items."

Limits Kutana enforces:

| Field | Limit |
| --- | --- |
| Instructions | 1 to 8,000 characters |
| Lead time before a meeting | 5 to 1,440 minutes |
| Assignment name | up to 120 characters |

- Set the lead time long enough for the work to finish before anyone joins.
- Write in plain words the person would use. The instructions show on the
  Assignment's card.
